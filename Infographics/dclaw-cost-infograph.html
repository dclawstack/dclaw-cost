The platform

One platform.
All your cloud spend.

DClaw Cost is a full-stack FinOps platform that unifies billing across every cloud provider, surfaces waste before it compounds, and delivers AI-driven savings recommendations at the moment engineers can act on them.

Built on the One Convergence design system and DKube's private AI infrastructure philosophy — your cost data stays in your infrastructure, full control, no vendor lock-in on the intelligence layer.

💸

$26B wasted annually

Cloud waste — idle instances, orphaned volumes, over-provisioned resources — most teams discover it months late.

📊

4 billing dashboards, 0 unified view

AWS Console · GCP Billing · Azure Cost Management · SaaS tools. No single source of truth, no cross-cloud comparison.

⏱️

Reactive by design

Budget alerts fire when the month is already over. FinOps teams spend hours on what AI can surface in seconds.

AI · Copilot architecture

A copilot that knows your numbers
before you ask.

Context assembly (parallel DB queries)
01
Monthly spend to date
billing_repo.total_spend(first_of_month, today)
02
Unacknowledged alerts
alert_repo.count_unacknowledged()
03
Open savings opportunities
recommendation_repo.total_savings()
04
Top 5 cost drivers

Security & Reliability Hardening

All P0–P2 product features are complete. The current sprint focuses on hardening for production deployment.

Critical — Production Blockers

P0.5.1 — Fix Frontend CI Pipeline

Critical

build-frontend.yml references ./frontend — directory doesn't exist. Change to ./web.

P0.5.2 — Logto JWT Authentication

Critical

PRD mandates Logto JWT on all /api/v1/* routes. All 136 endpoints are currently public.

P0.5.3 — Remove Hardcoded Secret Key

Critical

secret_key: str = "change-me-in-production" must be a required env var with no default.

P0.5.4 — Copilot Security

Critical

Auth, rate limiting (30 req/min), session ownership validation, error sanitization on SSE stream.

High + Medium Priority

P0.5.5 — Fix CORS Configuration

High

allow_origins=["*"] + allow_credentials=True is browser-rejected. Scope to explicit origins.

P0.5.6 — Billing Ingest Idempotency

High

Add source_record_id unique column. Pipeline retries create duplicate billing data without it.

P0.5.7 — Observability Stack

High

structlog + Prometheus metrics + Sentry DSN. PRD mandates structlog — no print() statements.

P0.5.8–11 — Service Tests, Frontend Tests, DPanel Manifest

Medium

Mutation score 32% → target 60%. Vitest for frontend. dclaw-manifest.json for DPanel.

Quick start

Running in 3 commands.

Option A — Docker
cp backend/.env.example \
  backend/.env
# add OPENROUTER_API_KEY

docker compose up --build -d

docker compose exec backend \
  alembic upgrade head

# → http://localhost:3036
# → http://localhost:8122/docs
Option B — Local Dev
cd backend
pip install -r requirements.txt
uvicorn app.api.main:app \
  --reload --port 8122

cd web
npm install && npm run dev
# → http://localhost:3036
Option C — Kubernetes
helm upgrade --install \
  dclaw-cost ./helm \
  --namespace dclaw \
  --create-namespace \
  --values helm/values.yaml \
  --wait
CloudNativePG manages PostgreSQL. K8s Secrets for API keys.
