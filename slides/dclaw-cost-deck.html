Deployment

Local in 3 commands. Kubernetes in 1.

Option A — Docker
cp backend/.env.example \
  backend/.env
docker compose up \
  --build -d
docker compose exec backend \
  alembic upgrade head
→ localhost:3036 · localhost:8122/docs
Option B — Kubernetes
helm upgrade --install \
  dclaw-cost ./helm \
  --namespace dclaw \
  --create-namespace \
  --values helm/values.yaml
CloudNativePG manages PostgreSQL
Option C — Local Dev
cd backend
uvicorn app.api.main:app \
  --reload --port 8122

cd web
npm run dev
Hot reload on both services
CI/CD Workflows
ci.yml — pytest + build build-backend.yml → GHCR build-frontend.yml → GHCR deploy.yml — Helm upgrade claude.yml — AI review
